# Pizzeria Mulino

The public menu of a single pizzeria, and the private tools its staff use to keep it current.

## Language

**Menu**:
The set of Pizzas the pizzeria offers; the public sees only the Available ones.
_Avoid_: Catalog, product list

**Menu Manager**:
A person allowed to change the Menu — today the pizzeria's owner, later possibly staff.
_Avoid_: Owner, admin, user
